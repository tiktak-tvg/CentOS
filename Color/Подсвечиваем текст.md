#### Как сделать, чтобы команды выводились не в чёрно-белом исполнении, а в подсвечивались 
>![Warning]
>Только с 8 версии Centos

Например, ``ls -la`` как подцветить цветом в консоли

##### Разовое использование

Просто добавьте флаг --color:
```bash
ls -la --color=auto
```
(В macOS вместо --color используется флаг -G: ls -laG)

##### Сделать цвета постоянными (Alias)
Чтобы не вводить флаг каждый раз, создайте «псевдоним» (alias) в конфигурационном файле вашего интерпретатора (обычно это .bashrc или .zshrc):

Откройте файл для редактирования:
```bash
nano ~/.bashrc
```

<img width="1101" height="190" alt="image" src="https://github.com/user-attachments/assets/6d53213e-5a07-4c27-8a87-61a62cf4f6d7" />

Добавьте в конец файла строку:
```bash
alias ls='ls --color=auto'
```

<img width="1074" height="271" alt="image" src="https://github.com/user-attachments/assets/f869ebac-695b-46c2-b6b3-6705c53f7d0f" />

Сохраните изменения (Ctrl+O, Enter, Ctrl+X) и обновите конфигурацию:
```bash
source ~/.bashrc
```
##### А как сделать цветным ip
Чтобы ip a всегда был цветным, добавьте алиас в тот же файл `` ~/.bashrc``:
- **Добавьте алиас**
Откройте файл:
```bash
nano ~/.bashrc
```
Добавьте в блок с алиасами (где вы только что правили ls) строку:
```bash
alias ip='ip -c'
```
- **Примените изменения**
```bash
source ~/.bashrc
```
#### Для 7 версии Centos использовать grc
Это самый простой и безопасный вариант для CentOS 7, так как он не трогает системные утилиты, а просто перекрашивает их вывод.

##### Установите зависимости (если их нет):
```bash
yum install -y python3 wget
```
##### Скачайте и установите grc:
```bash
wget https://github.com/garabik/grc/archive/refs/tags/v1.13.tar.gz
tar -xvf v1.13.tar.gz
cd grc-1.13
./install.sh
```
##### Настройте автозапуск для ip (и других команд). Добавьте в конец ~/.bashrc:
```bash
GRC_ALIASES=true
[[ -s "/etc/grc.sh" ]] && source /etc/grc.sh
##### Примените настройки:
```bash
source ~/.bashrc
```
