### Шаги сброса пароля
1. Входим в меню **GRUB**: перезагружаем систему. Когда появится меню выбора загрузки **GRUB**, быстро нажимаем клавишу **e**, чтобы войти в режим редактирования.

2. Перемещаем курсор (стрелками) в конец строки linux16 (после **LANG=en_US.UTF-8**).

3. Добавляем пробел и пишем: **rd.break**

4. Нажимаем **Ctrl + X** (или **F10**), чтобы запустить загрузку.

> Примечание: в CentOS 7 при использовании **rd.break** менять ro на rw в строке **GRUB** не обязательно, система сама перемонтирует разделы в режиме только для чтения, а команда **mount -o remount,rw /sysroot**, которую выполняем дальше, сделает нужный раздел доступным для записи.

После нажатия **Ctrl + X** система начнёт загружаться и остановится на приглашении:

```text
switch_root:/#
```
Там выполните по порядку:
```bash
mount -o remount,rw /sysroot
chroot /sysroot
passwd
```
Введите новый пароль (дважды). Затем обязательно выполните:
```bash
touch /.autorelabel
exit
exit
```
После этого система перезагрузится и обновит контексты SELinux. Когда загрузка завершится, мы сможем войти с новым паролем.
