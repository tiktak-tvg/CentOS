#### Чтобы задать статические параметры (IP, шлюз, DNS), выполните команды от имени root.

##### 1. Задайте IP-адрес и шлюз
Судя по вашему выводу, шлюз и DNS — это 10.1.100.11. Предположим, вы хотите оставить текущий IP 10.1.100.10:

```bash
nmcli connection modify ens33 ipv4.addresses 10.1.100.10/24
nmcli connection modify ens33 ipv4.gateway 10.1.100.11
```
##### 2. Задайте DNS-сервер
```bash
nmcli connection modify ens33 ipv4.dns "10.1.100.11"
```
##### 3. Переключите метод с DHCP на ручной
Это важный шаг, иначе NetworkManager продолжит пытаться получить адрес автоматически:
```bash
nmcli connection modify ens33 ipv4.method manual
```
##### 4. Примените изменения
Самый надёжный способ — перезапустить соединение:
```bash
nmcli connection down ens33
nmcli connection up ens33
```
##### Или скрипт
Рекомендуемый вариант: **локальный DNS + внешний резерв**
```bash
cat <<'EOF' > scriptnet.sh
#!/bin/bash
nmcli connection modify "ens33" \
  ipv4.method manual \
  ipv4.addresses 10.1.100.10/24 \
  ipv4.gateway 10.1.100.11 \
  ipv4.dns "10.1.100.11 8.8.8.8 8.8.4.4"
EOF
```
Перезагрузка сетевой карты
```bash
nmcli connection down "ens33" && nmcli connection up "ens33"
```
