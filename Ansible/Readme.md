#### Примеры plybooks ansible
1. first_playbook.yml (с правками) — развертывание репозиториев, установка Nginx и Vim, деплой динамических веб-страниц через шаблоны Jinja2.
**Оркестрация и Автоматизация:** установили Ansible, настроили файл инвентаря (hosts) для параллельного управления удаленными серверами и написали несколько сценариев (Playbooks).
**Сетевая безопасность:** настроили удаленные межсетевые экраны через модуль firewalld и научились управлять политиками SELinux (setsebool) для разрешения проксирования.
**Высокая доступность (HA):** развернули Reverse Proxy / Load Balancer на базе Nginx по алгоритму Round-Robin с автоматическими проверками здоровья нод (Health Checks).
**Динамический деплой:** освоили шаблоны Jinja2 (.j2), позволяющие генерировать уникальные конфигурации и веб-страницы на основе системных метрик серверов.
3. second_playbook.yml — автоматическое резервное копирование с использованием архивации (archive), делегирования задач (delegate_to) и сбора файлов на мастер-сервер (fetch).
4. third_playbook.yml — принудительная синхронизация системного времени в обход ограничений виртуализации, который автоматически синхронизирует время на всех серверах с помощью утилиты chrony.
5. fourth_playbook.yml — автоматическое резервное копирование с использованием планировщика cron на удаленных серверах, защита серверов по SSH-ключам.
**Автоматизация бэкапов по расписанию (Cron):**Добавить в нашу роль задачу, которая настроит планировщик cron на удаленных серверах, чтобы сценарий бэкапа из second_playbook запускался автоматически каждую ночь.
**Централизованный сбор:** Создадим регулярный скрипт на управляющем сервере centpca, который будет автоматически забирать созданные ночные архивы с удаленных серверов к себе в архив.
**Безопасность (Hardening):** Защитим наши серверы, отключим вход по небезопасным паролям через SSH, оставив доступ строго по SSH-ключам, и отключим удаленный вход для пользователя root (для повышения безопасности).
