#### Примеры plybooks ansible
1. first_playbook.yml (с правками) — развертывание репозиториев, установка Nginx и Vim, деплой динамических веб-страниц через шаблоны Jinja2.
2. second_playbook.yml — автоматическое резервное копирование с использованием архивации (archive), делегирования задач (delegate_to) и сбора файлов на мастер-сервер (fetch).
3. third_playbook.yml — принудительная синхронизация системного времени в обход ограничений виртуализации, который автоматически синхронизирует время на всех серверах с помощью утилиты chrony.
