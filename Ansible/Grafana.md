### Чтобы у вас появились красивые, сохраняемые графики, которые не пропадут, нужно поставить Grafana.
Она подключится к вашему Prometheus и покажет все эти же метрики в разы красивее и удобнее.

Вот команды для установки Grafana на вашу управляющую машину (centpca):
```bash
# 1. Скачать и установить Grafana
wget https://dl.grafana.com/oss/release/grafana-10.4.2-1.x86_64.rpm
yum localinstall grafana-10.4.2-1.x86_64.rpm -y

# 2. Запустить сервис
systemctl daemon-reload
systemctl enable --now grafana-server

# 3. Открыть порт в firewalld
firewall-cmd --permanent --add-port=3000/tcp
firewall-cmd --reload
```
После этого зайдите в браузере по адресу http://10.1.100.10:3000 (логин и пароль: admin, admin).
```txt
Это будет для одной ноды, в качестве примера покажу, но будем использовать другой вариант

В меню слева выберите Connections -> Data sources -> Add data source -> Prometheus.

В поле Connection URL укажите: http://10.1.100.10:9091

Нажмите Save & test (должно появиться "Data source is working").

В меню слева выберите Dashboards -> Import.

В поле Import via grafana.com введите 1860 и нажмите Load.

Выберите ваш Prometheus и нажмите Import.
```
##### Шаг 1: Импортируем простой дашборд
Делаем сразу для всех нод
```txt
Это будет для всех нод

В меню слева выберите Connections -> Data sources -> Add data source -> Prometheus.

В поле Connection URL укажите: http://10.1.100.10:9091

Нажмите Save & test (должно появиться "Data source is working").

В меню слева выберите Dashboards -> Import.

В поле Import via grafana.com введите 11074 (это официальный Node Exporter for Prometheus Dashboard EN) и нажмите Load.

Выберите ваш Prometheus и нажмите Import.
```

У вас появится огромный красивый дашборд с графиками CPU, памяти, дисков и сети для обеих нод. 

Он будет сохраняться в базе Grafana, и вы сможете открывать его с любого компьютера.

##### Шаг 2: Где искать ноды (фильтры)
Как только данные появятся, вы увидите графики. В самом верху дашборда у вас есть выпадающие списки-фильтры:

Job — оставьте node_exporter.

Instance — нажмите на него. Вот здесь будут ваши ноды! Появятся два IP-адреса: 10.1.100.12:9100 и 10.1.100.14:9100.

Если выбрать один IP — графики покажут только эту ноду.

Если выбрать All — графики покажут обе ноды сразу (на графиках будет две линии разного цвета).

##### Как добавить кнопку «All» (все ноды сразу)
В самом верху справа нажмите на иконку шестерёнки ⚙️ (Dashboard settings, она рядом с иконкой сохранения/дискеты).

В левом меню настроек выберите Variables (Переменные).

В списке найдите переменную instance и нажмите на неё, чтобы раскрыть настройки.

Прокрутите вниз до раздела Selection options (Опции выбора).

Найдите галочку Include All option (Включить опцию «Все») и поставьте её.

(Опционально) В поле Custom all value (Своё значение для «Все») можно вписать .* — это регулярное выражение, которое означает «выбрать все совпадения».

Нажмите кнопку Apply (Применить) в правом верхнем углу или просто вернитесь назад (стрелка влево).

Откроется новый дашборд. Вверху у него будет выпадающий список Instance.

Выберите в нём All.

Сразу же появятся графики с двумя линиями (для centpc1 и centpc3).

Нажмите иконку дискеты (Save) вверху, чтобы сохранить.

##### Теперь надо зафиксировать всё

Нажмите на иконку дискеты 💾 в правом верхнем углу (рядом с кнопкой Share). Это сохранит настройки дашборда (выбранные All для хостов и нод), чтобы при следующем открытии всё сразу отображалось.

Нажмите на иконку звездочки ⭐ (слева от дискеты), чтобы добавить этот дашборд в избранное (он появится на главной странице Grafana).

Теперь у вас есть полноценная система мониторинга:

Prometheus (на порту 9091) — собирает сырые данные с серверов каждые 15 секунд.

Node Exporter (на порту 9100 на каждой ноде) — отдает метрики операционной системы.

Grafana (на порту 3000) — рисует красивые графики и хранит историю.
